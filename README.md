# COUP — Socket.IO Multiplayer

## Quick start

```bash
npm install
npm start
```

Open `http://localhost:3000` in two browser tabs/devices to test multiplayer.

## Regression tests

```bash
npm test
```

The regression suite covers:
- Foreign Aid + Duke block
- Steal counter duplicate-turn protection
- Exchange manual selection card preservation
- Exchange timeout card preservation
